# ふくたあつこ 自己紹介スライド

講演の冒頭（2〜3分）で使う自己紹介ページです。ノートPCのブラウザで `index.html` を開いて、プロジェクターに映して使います。

## 使い方

| 操作 | キー |
|---|---|
| 次のスライドへ | → / ↓ / スペース / Enter / 画面の右側をクリック |
| 前のスライドへ | ← / ↑ / 画面の左側をクリック |
| 全画面にする・戻す | F |
| 最初・最後へ | Home / End |

プレゼン用のリモコン（ページ送りのクリッカー）でも操作できます。

## 写真の差し替え

`images` フォルダに次の名前で写真を置くと、仮の画像が自動で差し替わります。

- `images/profile.jpg` … プロフィール写真（1枚目・丸く切り抜かれます）
- `images/clinic.jpg` … クリニックの写真（2枚目）
- `images/family.jpg` … 家族写真（5枚目）

## スライド構成

1. タイトル「一生折れないこどもの自信を育む！」
2. わたしについて
3. 以前のわたし
4. 出会い（2024年 選択理論心理学）
5. いまのわたし
6. 今日から試してほしいこと
7. つながりましょう（Instagram @atsuko.fukuta と QRコード）

## 補足

- ネットにつながっていなくても動きます。ネットにつながっているときだけ丸ゴシック体の「Zen Maru Gothic」を読み込み、つながっていないときはPCに入っている丸ゴシック（Macはヒラギノ丸ゴ）などで表示します。
- QRコードは `images/instagram-qr.svg` に保存してあり、オフラインでも表示されます。
