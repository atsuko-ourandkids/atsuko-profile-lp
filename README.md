# ふくたあつこ 自己紹介ページ

初対面の方に「ふくたあつこ」を知ってもらうための、縦にスクロールして読む自己紹介ページです。スマホで見やすいように作っています。

公開URL: https://atsuko-profile-lp.vercel.app

## ページの構成

1. はじめまして（名前・歯科医師／保育士／2児の母・「一生折れないこどもの自信を育む！」）
2. わたしについて（あわ歯科こども歯科クリニック 副院長 など）
3. すきなこと（旅行・美味しいものを食べること・夏が大好き！）
4. わたしのストーリー（以前のわたし → 2024年 選択理論心理学との出会い → いまのわたし）
5. 大切にしている問い「この子と10年後、どんな関係でいたい？」
6. つながりましょう（Instagram @atsuko.fukuta とQRコード）

## 写真の差し替え

`images` フォルダに次の名前で写真を置くと、仮の画像が自動で差し替わります。

- `images/profile.jpg` … プロフィール写真（丸く切り抜かれます）
- `images/clinic.jpg` … クリニックの写真
- `images/family.jpg` … 家族写真

※ このページはインターネット上に公開されています。写真を入れると誰でも見られる状態になります。
